# Late Night Raid Roadmap

This roadmap outlines the current direction of [Late Night Raid](https://latenightraid.com/). It is a living document, not a promise of specific features or release dates. Priorities may change as Blizzard publishes new information and player needs become clearer.

## Guiding principles

- Help players answer practical questions quickly.
- Prefer first-party sources and make important claims traceable.
- Clearly separate confirmed information from details that may change.
- Keep guides readable on mobile and accessible to returning players.
- Protect the production website's private source code and infrastructure.

## Current focus

- Keep launch timing, beta access, name reservation, pricing, and edition information current.
- Maintain clear source links and visible update dates on time-sensitive guides.
- Improve navigation between the main overview and focused decision guides.
- Correct outdated details promptly when official information changes.
- Expand coverage of progression, zones, dungeons, raids, classes, and major systems when reliable details are available.

## Planned improvements

### Guide coverage

- Add more focused guides for common returning-player questions.
- Improve comparisons between editions, access paths, and key systems.
- Build clearer reference pages for group content, progression, and account-wide systems.
- Expand the FAQ as recurring player questions emerge.

### Data and tools

- Evaluate lightweight databases and lookup tools that solve specific player problems.
- Use structured, source-backed data where it improves accuracy and maintenance.
- Add practical utilities only when they are more useful than a well-written guide.

### Quality and trust

- Review links and time-sensitive claims on a regular schedule.
- Improve accessibility, mobile usability, performance, and search discoverability.
- Make corrections and material content changes easier to track.
- Keep public documentation aligned with the live website.

## Ongoing

- Monitor official announcements and support articles.
- Review community feedback and correction reports.
- Update this roadmap and the [changelog](CHANGELOG.md) when priorities or public features change.

## Not in scope

- Publishing the production website's source code, private configuration, or infrastructure.
- Acting as an official Blizzard support channel.
- Presenting rumors, leaks, or datamined details as confirmed information.

Suggestions are welcome through [GitHub Issues](https://github.com/mgayy520/late-night-raid/issues). Please see [CONTRIBUTING.md](CONTRIBUTING.md) before submitting a proposal.
