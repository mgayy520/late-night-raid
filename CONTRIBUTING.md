# Contributing to Late Night Raid

Thank you for helping make Late Night Raid more accurate and useful. This repository accepts feedback, corrections, feature ideas, and focused improvements to its public documentation. It is not the production website source repository.

## Before opening an issue

- Check the existing [issues](https://github.com/mgayy520/late-night-raid/issues) and [roadmap](ROADMAP.md) for a related item.
- Confirm that the report concerns Late Night Raid or its public documentation.
- Prefer first-party Blizzard or World of Warcraft sources for factual corrections.
- Never post passwords, API keys, tokens, account details, private configuration, or other sensitive information.

## Reporting a correction

Include:

1. The affected URL, file, or section.
2. The current text or claim.
3. The proposed correction.
4. A first-party source and its publication date, when available.
5. Whether the issue is time-sensitive.

## Suggesting a guide, database, or tool

Describe the player problem before proposing a solution. Explain who needs it, what decision it supports, and why the existing website does not already answer the question.

## Documentation pull requests

Small, focused pull requests are welcome for public documentation. Please:

- Use clear, natural English.
- Preserve the project's independent status and trademark notice.
- Link factual claims to reliable first-party sources where appropriate.
- Avoid keyword stuffing, promotional link exchanges, and unrelated backlinks.
- Do not add production source code, credentials, private configuration, or copied proprietary content.
- Explain what changed and why in the pull request description.

Submitting a proposal does not guarantee that it will be accepted or added to the production website.
